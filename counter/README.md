## 💻 Sobre o projeto

O **Counter** é um projeto desenvolvido com HTML, CSS e JavaScript para praticar os fundamentos da lógica de programação e a manipulação do DOM.

A aplicação consiste em um contador interativo que permite modificar um valor numérico por meio de ações do usuário, trabalhando conceitos como variáveis, eventos e atualização dinâmica da interface.

### 🎯 Objetivos do projeto

- Praticar a lógica de programação com JavaScript.
- Trabalhar com variáveis e operações matemáticas.
- Manipular elementos do DOM.
- Implementar eventos de clique.
- Atualizar valores dinamicamente na interface.
- Compreender a integração entre HTML, CSS e JavaScript.
