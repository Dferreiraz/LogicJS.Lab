## 💻 Sobre o projeto

O **Color Changer** é um projeto desenvolvido com HTML, CSS e JavaScript para praticar os fundamentos da programação e a manipulação do DOM.

A aplicação permite alterar dinamicamente as cores da interface por meio de interações do usuário, demonstrando como o JavaScript pode modificar os estilos de uma página em tempo real.

### 🎯 Objetivos do projeto

- Praticar a manipulação do DOM com JavaScript.
- Trabalhar com eventos de clique.
- Alterar estilos CSS dinamicamente.
- Compreender a interação entre HTML, CSS e JavaScript.
- Desenvolver interfaces simples e interativas.
