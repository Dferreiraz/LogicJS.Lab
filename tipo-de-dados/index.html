O tipo deste valor é:

Guia Rápido de Cores

String (Texto)
Number (Número)
Boolean (Lógico)
Null / Undefined

String

Textos sempre entre aspas.

let nome = "Ferreira"

Number

Números inteiros ou decimais.

let idade = 25
const pi = 3.14

Boolean

Apenas verdadeiro ou falso.

let maior = true
let pago = false

Null & Undefined

Ausência de valor proposital ou não definida.

let desc = null
let prod; // undefined
