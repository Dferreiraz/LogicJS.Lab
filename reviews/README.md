## 💻 Sobre o projeto

O **Reviews** é um projeto desenvolvido com HTML, CSS e JavaScript Vanilla para praticar a manipulação de dados e a criação de interfaces interativas.

A aplicação apresenta avaliações organizadas em uma estrutura de dados, permitindo navegar entre diferentes registros e atualizar dinamicamente as informações exibidas na página.

O projeto tem como foco o uso de arrays, objetos, índices e eventos para controlar a navegação entre avaliações.

### 🎯 Objetivos do projeto

- Praticar a manipulação de arrays e objetos em JavaScript.
- Trabalhar com índices para acessar elementos de uma coleção.
- Manipular o DOM para atualizar o conteúdo da página.
- Implementar eventos de interação com o usuário.
- Organizar dados e apresentá-los dinamicamente.
- Compreender a integração entre HTML, CSS e JavaScript.
