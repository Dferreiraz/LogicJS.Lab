## 💻 Sobre o projeto

O **Jogo do Clique — Tempo de Reação** é um projeto desenvolvido com HTML5, CSS3 e JavaScript Vanilla, com o objetivo de praticar lógica de programação e conceitos fundamentais do desenvolvimento Front-End.

O desafio consiste em clicar em um quadrado verde assim que ele aparecer na tela. O elemento surge em posições aleatórias, e o jogo mede o tempo que o jogador leva para reagir.

Além de proporcionar uma experiência interativa, o projeto permite explorar eventos, temporizadores, cálculos de tempo e manipulação dinâmica dos elementos da página.

### 🎯 Objetivos do projeto

- Praticar lógica de programação com JavaScript.
- Trabalhar com eventos de interação do usuário.
- Manipular elementos e estilos por meio do DOM.
- Utilizar temporizadores para controlar a dinâmica do jogo.
- Calcular o tempo de reação em milissegundos.
- Desenvolver uma aplicação simples e interativa.

## 🧠 Conceitos praticados

**Lógica de programação**
- Geração de posições aleatórias.
- Cálculos com valores de tempo.
- Controle do fluxo de execução.

**JavaScript e DOM**

- Eventos de clique com `onclick`.
- Temporizadores com `setTimeout`.
- Captura de timestamps para medir intervalos.
- Atualização dinâmica da interface.

- Organização do espaço de jogo.
- Estilização de elementos interativos.
